# 프차랩

가맹점 수, 점포당 연매출, 공개 창업비용으로 프랜차이즈를 비교하는 정적 웹사이트다. Vercel은 `public/`을 배포한다. 검색과 순위 계산, 상세 조회, 최대 네 브랜드 비교는 브라우저에서 처리한다.

## 공정위 데이터 갱신

1. 공공데이터포털에서 [브랜드 개요](https://www.data.go.kr/data/15109828/openapi.do), [가맹점 현황](https://www.data.go.kr/data/15110241/openapi.do), [창업 금액](https://www.data.go.kr/data/15110265/openapi.do) 각각의 활용을 신청한다.
2. GitHub Actions 비밀값 `FTC_DATA_SERVICE_KEY`로 일반 인증키(Decoding)를 저장한다.
3. 공식 샘플 응답의 금액을 동일 브랜드의 정보공개서와 대조한 뒤 GitHub Actions 변수 `FTC_REVENUE_UNIT_WON`, `FTC_COST_UNIT_WON`에 각각 원 단위 배율(1 또는 1000)을 등록한다. 선택 변수 `FTC_YEARS`는 쉼표로 구분한 조회 연도다. 비우면 실행 시점 한국 기준 현재 연도와 이전 두 연도를 탐색한다.
4. Actions에서 **공정위 가맹정보 일일 갱신**을 한 번 실행한 뒤 배포된 사이트의 기준 연도와 임의 브랜드 수치를 원문과 대조한다. 매일 한국 시간 오전 3시 17분에 예약되며, GitHub 실행 대기 시간에 따라 실제 시각은 달라질 수 있다.

세 응답은 기준 연도와 브랜드명·법인명·업종으로 결합한다. 결합 필드가 달라지면 해당 수치는 별도로 남거나 미공개 처리된다. 같은 식별 항목에 공시값이 충돌하면 해당 수치만 확인 필요로 남긴다. 불완전한 페이지가 발견되면 파일 교체 없이 실패한다. 목록은 공시된 자료의 범위에 한정된다. 자동 갱신 시 기존 공시 연도는 보존한다.

`data/brand-images.json`에는 사용 가능한 브랜드별 이미지를 `name`, `company`, `image` 필드로 등록한다. `image`는 `public/images/` 아래 자산의 웹 경로이거나 브라우저 코드에서 허용한 공식 이미지 URL이다. 이미지가 없으면 해당 브랜드의 글자로 표시한다. 기존 데이터 파일의 검증되지 않은 매출·비용·점포 수는 화면에 게시하지 않는다.

## 다단계판매 공시

다단계판매 탭은 [공정위 자료 다운로드](https://www.ftc.go.kr/www/selectBizMtlvlOpenList.do?key=226)의 연도별 공개 XLS를 사용한다. 매일 한국 시간 오전 3시 27분에 GitHub Actions가 최신 두 공시 연도를 확인하고, 앞서 수집한 연도는 보존한다. 연도 선택에는 공개 연도가 아닌 집계 대상 실적 연도를 표시한다. 서버 API 키는 필요하지 않다.

로컬에서 갱신하려면 Python 환경에서 `pip install -r scripts/requirements-mlm.txt` 후 `python scripts/sync-mlm.py`를 실행한다. 파일 열 검증이나 수집이 실패하면 기존 게시 데이터를 유지한다. 순위는 업체별 부가세 포함 다단계판매 매출의 내림차순으로 계산한다.
